# 独立 Android APK

本分支在已验证桌面633a021f上增加Android包装。Go协议引擎和tview/tcell界面直接编译成
APK里的共享库，JNI加载，不启动外部shell，不要求Termux，不在应用可写目录执行二进制。
终端采用MIT许可xterm.js 5.5.0和addon-fit 0.10.0，npm完整性锁定；所有JS/CSS随APK离线打包。
构建用锁定esbuild 0.25.9转译到Chrome61，带globalThis/queueMicrotask兼容层；
xterm唯一的Unicode Control正则等价改写为U+0000–001F/U+007F–009F，保留MIT许可。
不要求用户升级系统WebView来绕过可选链/空值合并解析错误。
WebView禁止外部导航、网络加载、文件和content访问；协议网络由内置Go引擎处理。

## 安装与平台

Actions产物为测试签名debug APK，包含arm64-v8a与x86_64，Android 8.0/API26以上。
ARM64为手机目标，x86_64用于原生模拟器验收。构建使用Android NDK与Go c-shared；
16KiB ELF段/ZIP对齐检查在CI执行。不是商店发行签名，不创建用户签名账户或长期凭据。
不同CI构建的临时debug签名可能不同；更新前先导出配置，必要时卸载旧版再安装。
卸载会移除应用私有数据。不要把测试签名当作生产发布身份。

## 触屏操作

顶部固定触屏按键提供执行、Tab、Esc、方向键、帮助、视图、表单、文件、保存、取消、
键盘、中文/多行输入和更多F6–F12/OPC四窗/翻页。也可用物理键盘。
最小80列终端可在竖屏横向滚动，横屏更适合完整表格；尺寸变化传回真实TUI。
输入按钮使用系统输入法，支持中文/emoji，经UTF8与终端粘贴事件送到当前输入位置。

配置在应用私有目录iotools.yaml，首次初始化只写本机示例，不自动连接。
表单=F3、文件=F4，保存=Ctrl+S；更多里可通过系统文件选择器导入/导出。
“只读模式设置”优先禁止协议修改和历史删除；“历史保存设置”默认关闭，明确启用后
将HTTP响应保存到应用私有history.sqlite，可能含敏感信息。切换设置会取消活动任务并即时生效，编辑草稿保留。
“导入证书/数据附件”只读取用户选定的单个文件（最多32MiB），不覆盖既有文件；
显示完整私有路径供F3/F4引用。“导出本机文件”可选择配置、响应、证书或历史备份
通过系统选择器输出（最多64MiB）；请自行确认敏感数据的目的地。
导入不超过1MiB，先验证配置，再原子替换并保留原配置备份；没有全盘存储权限。
127.0.0.1指手机本机；请明确编辑实际目标后再执行。
复制仍先经过TUI明确确认；应用不读取设备剪贴板。

## 生命周期与限制

切到后台只取消请求/订阅，保留真实TUI和未保存草稿在内存；返回恢复原页面并重绘，不自动重放请求。
导入文件选择器不会丢草稿，先校验新文件，再明确确认替换/丢弃草稿；取消继续原编辑。
操作系统终止进程会丢失未保存内存草稿，请用保存按钮持久化；不暗中将敏感草稿写盘。
未提供后台常驻服务、通知权限、开机启动、USB串口驱动或自动USB授权。
HTTP/Kafka/MQTT/Modbus TCP及RTU-over-TCP/OPC UA复用既有引擎。
物理USB/蓝牙串口和真实工业设备尚未验收；Android的ICMP权限按系统实际结果报告。
唯一普通运行权限是INTERNET；没有VPN、全盘存储、定位或相机权限。
TLS验证默认不放宽；明文HTTP/MQTT等协议只能通过用户明确配置及执行访问。

## 构建与证据

scripts/android/build-native.sh构建两个ABI；prepare-assets.sh按lockfile打包离线终端。
Android工作流构建debug APK、验证签名/权限/16KiB对齐，随后运行x86_64模拟器：已有KVM权限时Android35，否则较轻的AOSP Android29软件模拟。
模拟器测试真实启动Go TUI、明确点击触发本机HTTP回包、中文/emoji文件编辑持久化、
未保存中文草稿跨前后台保留、任务取消与不重放、恢复及横屏，并保存原生截图。
最终通过与否及下载文件以精确提交SHA的Actions为准；模拟器不代表实体ARM64手机验收。

CI只在已有/dev/kvm读写权限时使用硬件加速；否则软件模拟。不会更改设备权限、udev或宿主机安全设置。
