# Android 原生应用

Android 使用原生触控页面与共享 Go 协议引擎，支持 ARM64 手机和 x86_64 模拟器。桌面 Windows/Linux 继续使用轻量终端界面。移动端直接通过有大小限制的 UTF-8 JSON/JNI 接口调用协议引擎，不需要 Termux、外部运行时或网络页面。

## 页面与编辑

- 请求：按 HTTP、Kafka、MQTT、Modbus、OPC UA 筛选连接与请求，查看目标、动作及运行状态
- 工作台：协议专用参数表单、结果详情和持续任务；执行前显示真实目标，写入和危险操作需要明确确认
- 历史：查看已明确启用的本机请求历史，支持查询与管理
- 设置：环境配置、只读模式、历史保存、文件导入导出、证书与中文帮助

原生表单和完整配置编辑器均支持系统输入法、中文与 emoji。未保存草稿保留在内存，切换页面、前后台和方向时不自动丢弃；明确保存后写入应用私有目录。系统结束应用进程会释放未保存草稿。

配置默认位于应用私有目录 iotools.yaml，首次打开不连接任何服务。示例中的 127.0.0.1 指手机本机，请修改为实际目标再执行。导入通过系统文件选择器选取单个文件，校验后确认替换并保留备份；不会获取全盘存储权限。导出前自行确认文件内容及目的地。

## 协议与安全

HTTP 支持模板、请求链、加解密、响应转换与历史工作流。MQTT 提供发布/订阅与主题数据；Kafka 提供消息、主题、消费者、Schema Registry 和 Connect 操作；Modbus 提供 TCP、RTU-over-TCP 与数据解释；OPC UA 提供浏览、属性、读写、方法和订阅。具体操作以应用内动作目录与各协议指南为准。

协议修改、请求链写入、不安全 TLS 等操作逐项显示目标并请求确认。只读模式禁止写入；历史默认不保存，显式启用后可能包含敏感请求与响应。切到后台取消网络任务和待确认操作，返回不自动重放。没有开机自启或常驻后台服务。

USB 串口需手机支持 USB Host，并由用户选择设备、批准系统设备权限和打开端口；不能用普通 /dev 路径代替 Android 设备授权。物理 USB 与厂商工业设备的验证状态以最终验收记录为准。蓝牙串口不在当前支持范围。

## 构建与安装

Actions 使用 NDK/Go c-shared 构建 arm64-v8a 和 x86_64，检查 Android 依赖图不含桌面显示库、APK 签名、权限和 16 KiB 对齐，并运行实际 Android 模拟器操作测试及截图。最低 SDK 为 API26；最低版本声明不代表所有 Android 版本和 ARM64 真机已验证。具体通过的平台、提交和截图以 Actions 产物为准。

APK 使用临时调试签名，适合测试安装，不是商店发行签名。不同构建的签名可能不同，更新前先导出配置，必要时卸载旧版再安装；卸载会移除私有数据。不会创建用户签名账户或长期凭据。
