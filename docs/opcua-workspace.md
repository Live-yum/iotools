# OPC UA 四窗工作区

主界面选中OPC UA请求后按Ctrl+U，或OPC UA结果树/表格按D；F10订阅表也可按D。
打开只显示缓存，不主动连网；按r才发起当前节点的只读浏览、27属性和双向引用读取。

- 至少110×32同时显示浏览、属性、引用、独立订阅四窗
- 80×24等窄屏按1–4或Tab/Shift+Tab切换；节点、各窗缓存和后台订阅不因切换丢失
- 浏览/引用Enter下钻，退格回到上一节点，g输入明确NodeId；最多保留256个返回节点
- 属性Enter查看完整结构，e进入类型化编辑表单。所有写入仍受只读开关和完整目标确认约束
- 选中Method节点按c，读取方法签名并进入现有类型化参数流程；不自动调用方法
- s独立订阅当前/选中节点；S取消对应订阅，F8取消本工作区读取及全部独立订阅
- Esc关闭工作区、取消正在读取；独立订阅继续，可用F10管理。退出程序会取消全部工作
- Ctrl+Y先显示NodeId复制预览，明确确认后才发送系统剪贴板/OSC52

每次刷新共用请求总超时；浏览和引用各最多2000项，属性最多27项，独立订阅最多16个。
导航会取消旧读取，晚到结果不能覆盖新节点。忙时重复r不重复连接；所有调用只读，
不会在刷新/恢复时重放写入。跨服务器ExpandedNodeId不冒充当前服务器节点。

测试覆盖真实本机UA服务器的浏览/属性/引用及并行订阅、关闭保留订阅、大小屏布局和
键盘切换、重复刷新、旧结果隔离和取消退出。模拟终端截图并非物理Windows/ARM终端验收。
实际厂商方法、证书体系、工业设备与物理串口仍需获授权的现场验证。
