## 标注导入导出

在 Modbus 结果表格中：

- `I`：读取本机 JSON 文件或在文本框粘贴 JSON，再进入可滚动的合并预览
- 预览只处理当前请求对应的 holding/input/coil/discrete 空间；按“保存合并”才改本机集合文件
- 支持 MTUI `registers` payload 或完整配置中的 `registers` 部分；忽略设备连接、API、权限、其他空间，绝不连接或写入设备
- 合并遵循上游行为：固定地址取并集；相同地址的传入标签和规则覆盖对应旧值；未出现的标签、规则和固定项保留
- Esc/取消不保存；规则在下次用户主动执行读取时生效，导入不会自动开始读取
- `E`：将当前请求的固定项、标签、自定义规则导出为 MTUI registers JSON；不包含设备地址或认证参数
- `D`：导出当前已收到的寄存器行到 CSV，包括当前显示列、地址和原始 u16。导出不会读取额外设备范围，也不等同于整个设备内存 dump

文件导入最多4MiB，只接受普通文件；列宽等配置不能由标注导入隐式改变。
JSON语法、地址、重复项、自定义规则均在合并前校验。导出以0600权限新建文件，
拒绝覆盖已有文件。CSV按照地址排序，保留完整64位整数文本；文本字段可能触发
电子表格公式时加单引号防护。CSV同时区分导出UTC捕获时间与逐行响应接收时间。
标注I入口只处理标注；完整配置和CSV快照使用M更多菜单，详见[新增操作](modbus-more.md)。原始寄存器JSON快照仍用 `S`/`O`。

## 全解释列配置

`C` 打开列面板：

- 上下选择，Space切换显隐；`<`/`>` 调整列顺序
- `w` 设置所选列宽1..120，留空恢复自动宽度
- `a` 切换地址十进制/十六进制
- Tab/Shift-Tab依次访问列列表、搜索框以及各按钮；可搜索列名称或参数键
- “临时应用”只改变本次视图；“保存到请求”保存列顺序、显隐、宽度和地址模式；Esc/取消不改变布局

引擎提供的 u8/i8、u16/i16、u32/i32、u64/i64、f16/f32/f64、HEX、HEX32、
BCD/BCD32、二进制、ASCII、M10K、自定义解释全部可选，也包含固定、标签、差值、
趋势列。缺少后续原始寄存器的多字解释保持为空，不自动扩大读取范围。
至少保留一列；未知列、重复列和越界宽度拒绝。矩阵模式维持独立显示，返回表格
后恢复设置。示例：

```yaml
params:
  columns:
    visible: [address, label, u16, u64, f64, binary, custom]
    widths: {label: 18, custom: 24, u64: 22}
    address_mode: hex
```

## 作用域明确的快捷键

`K` 打开快捷键表单；填写单个可打印非空白字符，验证后保存。仅影响该请求的
Modbus结果表格。每个动作只保留一个有效按键；保存自定义键后，旧默认键不再
触发同一个动作。冲突（包括未改动的默认按键）拒绝保存。

支持 matrix、pin、label、filter、baseline、snapshot-save、snapshot-open、
columns、keymap、import、export、dump、more，以及[专用工作流](modbus-interactions.md)列出的19个动作。示例：

```yaml
params:
  keymap:
    pin: x
    columns: c
```

`q`、`?`、`+`、`-`以及Ctrl-C、F8、Esc、所有非字符键保留给全局安全与导航操作，
不能被重映射。自定义快捷键不影响弹窗；write只能打开同一安全写入流程，不改变只读权限。
只读模式仍可保存本机显示/标注配置；设备写入始终受独立确认和只读限制。

本机配置保存会检查文件是否被外部修改；冲突时拒绝覆盖。采样运行中不允许保存
标注或持久化偏好；临时列布局可以用于观察当前结果。

## 精确差异与验证

已补齐此范围的原生交互：标注JSON文件/粘贴导入、明确合并预览、保存/取消、
标注JSON导出、当前读取数据CSV导出、列显隐/顺序/宽度/过滤以及表格动作快捷键。

仍与上游不同：

- 不读取系统剪贴板；可经明确确认写系统/终端剪贴板，或粘贴文本/使用本机文件
- 完整配置可经M转换设备、启动范围和适用设置，明确预览追加四个只读请求；未转换的主题/API/策略逐项报告
- 未提供上游全部32个动作的任意键重映射，只映射当前真实提供的32个原生动作（并非上游32个动作的一一对应）；安全按键固定
- time列和M时间选项提供UTC/相对时间；CSV区分采样和导出时刻，相对值在数据或视图重绘时更新
- CSV现在覆盖线圈/离散输入，M可导入CSV快照；没有目标元数据时需要用户核对设备/unit

本轮测试使用tcell模拟屏幕和临时文件，验证导入合并、跨空间隔离、取消、显式保存、
外部修改冲突、只读边界、公式防护、拒绝文件覆盖、64位精度、列布局及全键盘按钮
可达性。没有连接实际工业设备。


公共剪贴板支持已补充：结果表Ctrl-Y、Kafka详情Ctrl-Y先预览再明确确认；Windows使用系统API，
其他平台使用终端OSC52，不依赖xclip/pbcopy。终端/SSH可因安全策略拒绝OSC52，程序不声称已写成功，
仍可使用粘贴/文件导出。CI只检查Windows API可用性，不读取或修改用户剪贴板。
