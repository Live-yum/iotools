# OPC UA 扫描、快照与实时记录（TUI）

在 OPC UA 四窗工作区（Ctrl+U）按 **B** 打开扫描工作区。打开界面不连接服务器；
明确启动后，从选定根 NodeId 自动遍历本服务器的正向层级引用。沿用请求的身份、
安全策略和证书校验，不自动信任证书、不写变量、不调用方法、不扫描其他服务器。

## 工作流程

1. 指定扫描根和节点数边界，开始扫描；深度默认不限（max_depth: 0），需要时才显式设置正数限制。可以随时取消；达到上限、访问失败或
   取消时，结果明确标为不完整，不能将“已发现变量”当作服务器全部变量。
2. 在变量表勾选需要的节点，或全选已发现变量。Object/Method 等非变量不能作为
   变量选中；NodeId 的字符串标识区分大小写。扫描同时绑定服务器 NamespaceArray，
   后续批量读和订阅会重新核对；索引映射改变时拒绝执行并要求重新扫描。
3. 批量读取已选变量。读取按批次复用会话，保留每节点值、类型、状态以及源和
   服务器时间戳。坏状态或部分失败不会被伪装成空值成功。
4. 将所选结果导出为 CSV 或 JSON 快照。文件可能包含敏感业务数据，应选择受控的
   本地目录；只创建新文件，不覆盖已有文件。CSV 对可能被表格软件当作公式的
   字符串作安全处理；JSON 适合保留原始结构。NaN/Infinity 使用显式标签编码；无法可靠解码的
   值会报错，不能静默导出为空对象。
5. 对所选变量启动实时订阅，或明确指定新文件记录到 CSV / JSONL。订阅复用一个
   会话，不为每个变量创建连接。JSONL 是每行一条 JSON 事件，不是 JSON 数组快照。
   停止、取消及退出会清理本工作区任务和记录文件；发生断线或写入失败时停止并显示状态；文件保留连接和停止事件。

## 快捷键

- r：配置并开始扫描；Tab / 1 / 2：切换树与变量表
- 空格：切换变量选择；a：全选已发现变量；n：清空选择
- v：批量读值；e：导出 CSV / JSON 快照
- s：实时订阅（不写盘）；l：订阅并记录 CSV / JSONL
- S / F8：停止；Enter：节点详情；i：完整状态/扫描摘要；Esc：关闭并停止本工作区；Ctrl+C：退出

正在读值、订阅或导出时锁定选择；停止后可修改。扫描中的全选只包含当时已发现的
变量，不会偷偷扩大到稍后发现的节点。

## 边界

- 扫描默认不限制深度（max_depth: 0），不会因默认层数停止；采用迭代队列和
  NodeId 去重防循环，不依赖递归调用栈。显式 max_depth: 1..256 才限制深度。
- 默认最多 10,000 个节点，每节点最多 1,000 条引用；超时、取消、访问失败或达到
  任一显式上限仍会标记扫描不完整。不限深度不等于无限资源或保证所有点位可访问。
- 一次批量读最多 10,000 个节点；默认每批 100 个。
- 本工作区一次订阅最多 1,000 个节点，实际服务端可能有更低限制；错误必须显示。
- 文件记录最多 100,000 行（包括连接/停止事件）/ 128 MiB / 24 小时。达到边界后
  停止，而非无限占用磁盘。缺少结束事件或出现错误时应视为可能不完整。
- 扫描工作区的批量订阅不自动重连：服务器重启后 namespace 索引可能变化，断线后请
  重新扫描、选取并订阅，避免把旧 NodeId 指向不同变量。其他既有单节点订阅行为不变。
  不补录断线数据；采样率、服务器队列、UI和磁盘背压都会影响观测结果，实时记录
  不等同于完整工业历史库或保证无丢样的采集系统。
- 仅对用户明确配置并有权访问的目标执行操作。不要把真实证书、凭据、私有端点、
  导出数据提交到仓库。

## 实现来源与验证说明

交互流程参考 [BartK1990/OpcUaExporter](https://github.com/BartK1990/OpcUaExporter)
（MIT），本项目复用自己的 Go 协议引擎和 TUI，未嵌入或运行该 .NET 程序。
原参考项目的 CSV/JSON 导出主要是节点元数据；这里的目标是同时支持值快照与实时记录。

回环 OPC UA 服务测试验证实际协议连接；模拟终端用于键盘、布局和生命周期测试。
这些都不能替代厂商设备、实际 Windows/ARM 终端、生产网络及长期采集的现场验收。
